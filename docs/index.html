三个核心术语

SSRL
Socially Shared Regulation of Learning，群体共同调节学习过程。
HASRL
Human–AI Shared Regulation of Learning，关注人和 AI 共同参与调节。
MAI
Metacognitive AI agent，以识别学习过程中的提示时机为研究方向。

METHOD & PROVENANCE

如何建立这份研究图谱

透明呈现资料类型、整理路径和验证边界，让每一条线索都有回到来源的入口。

A / 采集

公开资料与学术 API

组合 arXiv、OpenAlex、研究机构与项目官方页面。采集失败单独记录，不把 HTTP 错误或验证码误写为“无研究结果”。

B / 分类

区分论文与研究资料

学术论文、研究者、官网、会议、政策和新闻采用独立分类。旧数据的 41 条记录已无损分类为论文与资料。

C / 留痕

每周增量、来源与修订

按来源去重、保存每周报告、生成数据清单并通过 Git 留存修订历史。最新增量和长期累计不能直接混为一谈。

OPEN RECORDS / PUBLIC EVIDENCE

页面为持续扩展的研究索引；系统部署规模、模型效果与论文结论应以原始文献及相关机构发布为准。若发现错误，可在仓库提交 Issue。
